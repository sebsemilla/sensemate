SenseMate MCP Server

Conecta tu agente IA al contenido educativo de SenseMate: posts de idiomas, clases disponibles y bots generadores via Model Context Protocol.

📡 MCP 2025-03-26 ⚡ HTTP Streamable 🖥️ stdio 🆓 Lectura gratuita

🛠️ Herramientas disponibles

get_feed
Obtiene publicaciones recientes del Live Feed. Contenido educativo sobre idiomas con datos schema.org incluidos.
Acceso público
get_classes
Lista clases disponibles o en vivo del Class Room. Filtrá por disponibles o live.
Acceso público
list_bots
Lista todos los bots de contenido con sus configuraciones, schedules y estadísticas.
Requiere admin_token
run_bot
Ejecuta un bot manualmente para generar contenido nuevo de inmediato con DeepSeek AI.
Requiere admin_token
create_bot
Crea un nuevo bot con prompt personalizado, periodicidad cron y tipo de schema.org.
Requiere admin_token
get_bot_logs
Historial de las últimas 20 ejecuciones de un bot: éxitos, errores y tiempo de respuesta.
Requiere admin_token

🔌 Cómo conectarse

Claude Desktop

Agrega esto a tu claude_desktop_config.json:

{
  "mcpServers": {
    "sensemate": {
      "type": "http",
      "url": "https://sensemate.app/mcp"
    }
  }
}

Reinicia Claude Desktop. Verás las herramientas de SenseMate disponibles en la barra de herramientas.

Cursor / Continue.dev

En tu archivo de configuración de MCP servers:

{
  "mcpServers": {
    "sensemate-content": {
      "url": "https://sensemate.app/mcp",
      "transport": "http"
    }
  }
}

HTTP Streamable (cualquier cliente MCP)

Endpoint: POST https://sensemate.app/mcp

Inicia una sesión e invoca herramientas con el protocolo JSON-RPC 2.0:

# 1. Initialize
curl -X POST https://sensemate.app/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{
    "protocolVersion":"2025-03-26",
    "capabilities":{},
    "clientInfo":{"name":"my-app","version":"1.0"}
  }}'

# 2. Llamar una herramienta
curl -X POST https://sensemate.app/mcp \
  -H "Content-Type: application/json" \
  -H "mcp-session-id: <session-id-del-paso-1>" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{
    "name":"get_feed",
    "arguments":{"limit":10}
  }}'

Modo stdio (servidor local)

Si tenés acceso al servidor:

# Cloná el repo y corré directamente
node mcp_server.cjs

O configurá como proceso en Claude Desktop:

{
  "mcpServers": {
    "sensemate-local": {
      "command": "node",
      "args": ["/ruta/a/sensemate/mcp_server.cjs"],
      "env": {
        "ADMIN_TOKEN": "tu-token-de-admin"
      }
    }
  }
}

❓ Preguntas frecuentes

¿Qué es el Model Context Protocol?

MCP es un estándar abierto creado por Anthropic que permite a los agentes IA (como Claude) conectarse de forma segura a fuentes de datos y herramientas externas. Funciona como un "USB para IA": un protocolo universal que cualquier cliente puede implementar.

¿Los endpoints de lectura son completamente públicos?

Sí. get_feed y get_classes (y sus equivalentes REST) no requieren autenticación. Las herramientas de escritura y administración (create_bot, run_bot, etc.) requieren un admin_token.

¿Puedo usar los datos para mi propia app?

Sí, con atribución. Los datos de la API REST y MCP son de uso libre para proyectos educativos. Para uso comercial, consultá los Términos de servicio.

¿Qué schema.org incluye cada post?

Cada publicación generada por un bot incluye un JSON-LD con uno de estos tipos: Article, LearningResource, Course, EducationEvent o FAQPage. Podés inyectarlo directamente en el <head> de tu página.

¿Dónde está el código fuente?

El servidor MCP está implementado en mcp_server.cjs dentro del proyecto SenseMate. El protocolo es compatible con la especificación MCP 2025-03-26.
